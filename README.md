# LightNation Check-In

LightNation Check-In is a modern digital check-in application designed to simplify attendance management for churches. The application provides an intuitive interface for checking in children, tracking attendance, and improving the overall check-in experience.

## Features

- Child check-in and check-out
- Clean and responsive user interface
- Fast search and selection
- Attendance tracking
- Status badges
- Mobile-friendly design

## Tech Stack

### Frontend
- React
- JavaScript (JSX)

### Backend
- Backend integration in progress

## Project Status

The frontend interface has been completed.

Backend development is currently in progress, including:

- Authentication
- Data persistence

## Installation

Clone the repository:

```bash
git clone https://github.com/Oluwayemisi429/lightnation-checkin.git
```

Navigate into the project:

```bash
cd lightnation-checkin
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

## Purpose

This project was created to provide churches with a modern, user-friendly digital check-in system that improves attendance management and enhances the experience for volunteers, parents, and administrators.
